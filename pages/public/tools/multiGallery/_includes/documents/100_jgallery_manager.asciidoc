== Manager Instance

The MultiGallery below is called the *Manager Instance*. It starts out
*empty* because its entry in `gallery_media.yml` does not have any images.
Everything you add appears *in the browser* and stays there using the
browser's *localStorage*, not in the site's YAML files. This makes it a
good place to try out the J1 extensions of the module without changing
any files.

The manager has the *manage bar* turned on (`manage.enabled: true`),
shows the title *Gallery Manager*, includes the *search bar* (`search.enabled: true`),
and displays item tools on every tile (`manage.showItemTools: true`).
It opens its images in the *PhotoSwipe* lightbox (`lightbox.type: ps`) and
measures the size of each image itself (`photoswipe.auto_detect_size: true`),
since images added while running do not have `width` and `height` set.
