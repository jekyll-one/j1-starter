[role="dropcap"]
The MultiGallery module organizes images into evenly aligned rows. Each row
has the same height, but the images within each row can have different widths.
This layout style is similar to what you see on photo sites like Flickr or
Google Photos.

[role="mb-4"]
The photos you take are usually a mix of *landscape* and *portrait*
orientations. A simple grid would have to crop them or leave gaps.
J1 MultiGallery solves this by keeping each image in its original
shape and adjusting the widths so every row fills the page neatly.
